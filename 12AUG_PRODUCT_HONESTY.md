# 12-Aug product honesty

Sentinel now models build-time dependency execution, dependency-graph risk, platform-specific
native fetch correlation, persistence after initial artifact removal, static capability levels, and
source/canonical-impact separation. These are bounded static or synthetic models.

Sentinel does not claim live build-time protection, universal SStar detection, malware-family
coverage, LaunchAgent-as-malware semantics, runtime capability from symbols, or recency from feed
ingestion. Production key authority, automatic remediation, and Tauri transactional response remain
disabled or unimplemented.

# Detection Quality Metrics

implementation_authority: NONE
current_runtime_status: DESIGN_ONLY

Measure precision and recall only on labeled, versioned corpora with class distribution disclosed.
Track false-positive rate by host role, missed-simulation rate, alert volume, telemetry completeness,
contradicting-signal usage, evidence-quality distribution, privacy violations, processing latency,
queue depth, dropped-event count, and analyst disposition time.

No target is a measured result. Every performance report records hardware, OS build, storage, corpus,
ruleset, concurrency, cache state, sample size, command, and result distribution. Rule promotion stops
when privacy, availability, evidence integrity, or error-budget gates fail.
